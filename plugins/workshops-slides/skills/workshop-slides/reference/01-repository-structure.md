# Repository Structure

This is the file structure of a workshops.de Slidev workshop repository.
It is based on the template at https://github.com/workshops-de/workshop-slides-template

```
/
├── .github/
│   ├── dependabot.yml                   # Weekly updates of the workshops.de packages (one grouped PR)
│   └── workflows/
│       └── deploy.yml                   # Calls the toolkit's reusable deploy workflow (DO NOT MODIFY)
├── .claude/
│   └── settings.json                    # Enables the workshops.de Claude Code plugin
├── .gitignore
├── .nvmrc                               # Node version (v24)
├── 00-index.md                          # Index slide deck with links to all lessons
├── slides.md                            # Combined slide deck for presenter view
├── sources.md                           # Sources and references
├── package.json                         # Theme + toolkit, scripts, Prettier config reference
├── package-lock.json                    # Lock file (generated by npm install, npm 11)
├── og-image.png                         # Social sharing image
├── lessons/
│   ├── 01-lesson-name/
│   │   ├── lesson.yml                   # Lesson metadata (synced to platform)
│   │   ├── 01-lesson-name.md            # Main Slidev entry point for this lesson
│   │   ├── slides/
│   │   │   ├── topic-one/
│   │   │   │   └── topic.md             # Slide content following 4-MAT
│   │   │   └── topic-two/
│   │   │       └── topic.md
│   │   └── tasks/
│   │       ├── 01-first-task/
│   │       │   ├── task.yml             # Task metadata
│   │       │   ├── body.md              # Main task description
│   │       │   ├── hint.md              # Collapsible hints
│   │       │   ├── bonus.md             # Bonus challenges (optional)
│   │       │   └── trainer_hint.md      # Trainer notes (optional)
│   │       └── 02-second-task/
│   │           ├── task.yml
│   │           ├── body.md
│   │           └── hint.md
│   ├── 02-lesson-name/
│   │   └── ...
│   └── 03-lesson-name/
│       └── ...
└── public/
    └── 01-lesson-name/
        └── topic-name/
            └── images...                # Public images referenced in slides
```

## Key Conventions

- Directory names use kebab-case with numeric prefix: `01-getting-started`
- The lesson entry .md file name matches the directory name: `01-getting-started/01-getting-started.md`
- Topics are organized in `slides/topic-name/topic.md`
- Tasks are in `tasks/NN-task-name/` with separate files for metadata and content
- `npm run build` (the `workshop-slides` CLI from `@workshops.de/slidev-toolkit`) auto-discovers lessons by scanning `lessons/*/*.md` with `base:` and `out:` in the headmatter, builds them into `dist/<lesson>/` and exports a PDF per lesson
- GitHub Actions deploys to GitHub Pages automatically on push to main (Settings → Pages → Source must be "GitHub Actions")
- Look and feel (layouts, code highlighting, Mermaid, shortcuts) come from `@workshops.de/slidev-theme`; build, deploy and core dependencies from `@workshops.de/slidev-toolkit`. Do not add `setup/` or `styles/` folders to the repository root: Slidev does not load them for lesson decks.
- The platform syncs lessons and tasks from the repo via `github_course_url`

## Files You Generate vs. Files from Template

**Generate these** (workshop-specific content):
- `00-index.md`
- `slides.md`
- `sources.md`
- All files under `lessons/`

**Keep from template** (do not regenerate):
- `package.json` (only update the `name` field)
- `.github/workflows/deploy.yml`
- `.github/dependabot.yml`
- `.claude/settings.json`
- `.gitignore`
- `.nvmrc`
